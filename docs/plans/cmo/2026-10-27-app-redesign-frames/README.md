# App redesign frames (2026-10-27)

Source files of the Claude Design canvas https://claude.ai/artifact/QqAc6RuZi44osR3YAXAuNw, copied for the sessions
that build [`../2026-10-27-ui-build-plan.md`](../2026-10-27-ui-build-plan.md). One `.dc.html` per artboard;
`canvas.json` lists them with their titles. They are design references, not app code: read the exact sizes, colours
and copy from them, and rebuild the screens with the app's own components. Numbers in them are sample data.

The canvas is the live version; if the two differ, the canvas wins and these copies get refreshed.
