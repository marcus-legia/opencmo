   bar shows `Pro · 60% used`; Settings › Plan and billing shows the bar and the reset date. Credits keep working
   underneath; only an AI image keeps a visible price. A paid account's `sales_reply_drafts` costs 0.
2. **The free scan, once more when it found no one.** If an unpaid account's only free `sales_scan` ended with
   `verdict = "none"`, it may run one more free scan after editing Strategy.

4. **The morning email**: weekdays at 8:00 by default; people asking first (at most 3, source, match, one quote, one
   link), up to 2 follow-ups, one line for posts with the next deadline; no "Went out", no "Stuck"; not sent when
   nothing is new (logged as skipped); a footer that is always true. **Expiring-card emails are removed**; a founder

6. **Chat folds** to an "Ask" button on every view but Feed.
7. **Landing FAQ** says what is true now: no video or slideshow answer, fair use instead of credits, the free scan.

## The shared contract (A1 pushes it first)

```ts
// apps/web/lib/billing/usage.ts (new)
export type PlanUsage = {
  plan: "free" | "pro";
  interval: "month" | "year" | null;
  used: number;        // credits spent this period
  allowance: number;   // credits the plan gives per period (billing_catalog.credits)
  percent: number;     // 0..100, rounded down
  resetsAt: string | null;
  paused: boolean;     // percent >= 100: new scans wait for the reset
};
```
RPC `plan_usage()` (RLS, the founder's own) returns those fields; the screens loader exposes `usage: PlanUsage` on
`settings` and the shell props.

Email settings: `profiles.digest_days text not null default 'weekdays' check (digest_days in ('weekdays','daily','monday','off'))`,
`digest_hour` default becomes 8. `email_log` gains `subject text`, `summary jsonb`, status `skipped`, and `kind`
`'digest' | 'weekly' | 'push'` (`expiring` stays readable for old rows, no new ones).
