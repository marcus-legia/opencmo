# Architecture

Target designs for OpenCMO, written before they are built. `ARCHITECTURE.md` at the repo root describes the system
as built; when a design here ships, move its decisions there.

Every page is a pair with the same name: an `.html` page for people (diagrams, opens in any browser) and an `.md`
twin for agents. The two must say the same thing; change both in the same commit.

|---|---|
