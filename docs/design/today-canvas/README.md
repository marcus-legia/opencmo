# OpenCMO Today canvas

The artboards of the "OpenCMO Today redesign" canvas (claude.ai/artifact/77MyWuSem4GCssg7Bx11wi), copied as they were
published on 2026-11-10. They are the spec of the v2 app UI: each screen is built to match its artboard.

- `apps/web/styles/today.css` is generated from these files: `python3 apps/web/scripts/port-today-css.py docs/design/today-canvas > apps/web/styles/today.css`.
- After the canvas changes, copy the new files here, run the script again, and compare each screen with its artboard.
